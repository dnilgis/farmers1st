FFAI API v4.0

← Back to FFAI

Free, open access to the Farmers First Ag Index: what U.S. farms are paid against what they pay, every quarter since 1995. No API key. No rate limits. No auth. Just JSON.

License: CC BY 4.0 — use freely with attribution to Farmers First Agri Service (farmers1st.com). Built from USDA NASS price data; updated quarterly once USDA has published all three months of a quarter. Tested internally against USDA net farm income; not reviewed or endorsed by USDA, RMA, or FCIC.

Endpoints (v4, current)

Current Quarter

GETJSON
https://farmers1st.com/api/v4/current.json
Latest all-farms score and ratio, crop/livestock/dairy scores and ratios, previous quarter. ~1 KB.

Historical Time Series

GETJSON
https://farmers1st.com/api/v4/history.json
Every quarter since Q1 1995: ratio and score for all farms, crops, livestock and dairy.

Method & Validation

GETJSON
https://farmers1st.com/api/v4/meta.json
USDA series used, how the score is computed, the pre-registered validation and its results, and the limits.

Embeddable Badge

GETJS
https://farmers1st.com/api/v4/badge.js
Self-rendering widget. Drop two lines of HTML onto any page.

Fields

FieldTypeDescription
scorefloatAll-farms score, 0-100: share of 1995-2019 quarters whose ratio was at or below this quarter’s.
regimestringSTRONG (70+), FAVORABLE (55-70), GUARDED (40-55), STRESSED (0-40)
ratiofloatUSDA index of prices received divided by prices paid, × 100 (2011 = 100).
sectors.cropsobjectCrop prices received / prices paid by crop farms: ratio, score, regime.
sectors.livestockobjectMeat animal prices received / prices paid by animal farms.
sectors.dairyobjectDairy prices received / prices paid by animal farms.
quarterstringQuarter label, e.g. "Q2'26"
datestringISO date of quarter start (YYYY-MM-DD)

Only the all-farms score was validated (against USDA net farm income, year over year). Sector scores are descriptive. Details in meta.json and the methodology.

Code Examples

JavaScript (fetch)

fetch('https://farmers1st.com/api/v4/current.json')
  .then(r => r.json())
  .then(d => {
    console.log(`FFAI: ${d.score} ${d.regime} (ratio ${d.ratio})`);
    console.log(`Crops: ${d.sectors.crops.score}`);
    console.log(`Livestock: ${d.sectors.livestock.score}`);
    console.log(`Dairy: ${d.sectors.dairy.score}`);
  });

Python

import requests, pandas as pd

h = requests.get('https://farmers1st.com/api/v4/history.json').json()
df = pd.DataFrame(h['quarters']).set_index('date')
print(df[['ratio', 'score']].tail())

curl

curl -s https://farmers1st.com/api/v4/current.json | python3 -m json.tool

R

library(jsonlite)
ffai <- fromJSON("https://farmers1st.com/api/v4/history.json")
plot(ffai$quarters$ratio, type="l", main="Prices received / paid")

Notes

CORS: GitHub Pages serves all files with permissive CORS headers. Fetch from any origin.

Rate limits: None. It’s static JSON on a CDN.

Update cadence: Quarterly, after USDA NASS has published all three months of the quarter (about a month after the quarter ends). The generated field in each response tells you when.

Revisions: the score is measured against a fixed 1995-2019 base, so published values change only if USDA revises its own data.

FFAI v3 (retired, frozen)

FFAI v3 (Federal Reserve series, Q1 2008 – Q2 2026) was retired in October 2026 after testing showed its composite mostly followed the Fed Funds interest rate. As promised when v3 launched, its endpoints stay online and unchanged: /api/v3/current.json, /api/v3/history.json, /api/v3/meta.json, /api/v3/badge.js. They will not be updated.
